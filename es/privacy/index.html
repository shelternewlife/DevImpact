Privacidad y transparencia

Política de privacidad

Esta página explica el alcance de la privacidad en el sitio web de DevImpact y cómo encontrar la información de privacidad aplicable a cada una de sus aplicaciones.

1. Alcance

Este aviso se aplica al sitio web público de DevImpact alojado en GitHub Pages. No sustituye ni prevalece sobre las políticas de privacidad, declaraciones ni información de Seguridad de los datos que puedan corresponder a una aplicación Android concreta.

2. Interacciones con el sitio web y servicios externos

Este sitio web es un catálogo informativo estático. Incluye enlaces a Google Play, GitHub y al correo electrónico. Cuando sigues un enlace externo o contactas con un tercero, ese servicio puede tratar información conforme a sus propias condiciones de privacidad. El alojamiento y la distribución mediante GitHub Pages pueden implicar el tratamiento de datos técnicos de las solicitudes por parte de GitHub, de acuerdo con sus propias condiciones.

Este sitio web no ofrece registro de cuentas, perfiles de usuario, formularios de pago ni un servicio de mensajería integrado.

3. Información de privacidad específica de cada aplicación

Cada aplicación Android puede tener sus propias prácticas de tratamiento de datos y declaraciones de privacidad. Antes de instalarla o utilizarla, consulta la sección Seguridad de los datos y el enlace a la política de privacidad proporcionado por el desarrollador en su ficha oficial de Google Play, si está disponible. Esas declaraciones específicas se aplican a la aplicación correspondiente.

4. Información relacionada con la edad

La edad recomendada y la información sobre el público destinatario pueden variar según la aplicación. Antes de utilizarla, consulta la clasificación por edades y las declaraciones correspondientes en su ficha de Google Play.

5. Cambios y contacto

Este aviso puede actualizarse cuando cambien el sitio web o sus prácticas. Si tienes preguntas sobre la privacidad del sitio, escribe a carta.net.play@gmail.com.
