Nous contacter

Contacter DevImpact

Pour toute question concernant nos applications, pour nous faire part de vos commentaires ou pour une demande commerciale ou de partenariat, contactez DevImpact par e-mail.

E-mail

Pour toute demande générale, utilisez l’adresse ci-dessous. Indiquez le nom de l’application concernée et les informations utiles afin que votre message soit orienté vers le bon interlocuteur.

carta.net.play@gmail.com

Assistance sur les applications

Lorsque vous nous contactez au sujet d’une application, indiquez son nom exact, le modèle de votre appareil, la version d’Android utilisée et une description précise du problème. Ne communiquez aucun mot de passe ni aucune information de paiement sensible.

Activités commerciales et partenariats

Pour toute proposition de collaboration, présentez votre organisation, l’objet de votre demande et le meilleur moyen de vous recontacter.

Informations officielles sur les produits

Pour consulter les descriptions, les captures d’écran, la disponibilité et les informations sur l’éditeur, rendez-vous sur le profil officiel de DevImpact sur Google Play.
