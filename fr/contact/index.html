Parlons de votre demande

Pour une question sur nos applications, un commentaire, une demande professionnelle ou une proposition de partenariat, contactez-nous par e-mail.

Adresse e-mail

Précisez le nom de l’application et le contexte de votre demande afin de faciliter son traitement.

Assistance sur une application

Indiquez le modèle de votre appareil, la version Android et une description claire du problème. N’envoyez jamais de mot de passe ni de données de paiement sensibles.

Partenariats

Présentez votre organisation, l’objet de votre proposition et la meilleure manière de vous répondre.

Informations officielles sur les produits

Pour consulter les descriptions à jour, les captures d’écran, la disponibilité et les informations du développeur, visitez le profil officiel DevImpact sur Google Play.

Avant d’envoyer un message

Pour faciliter le traitement de votre demande, indiquez le nom exact de l’application et décrivez clairement le contexte. Pour un problème technique, précisez le modèle de votre appareil et la version d’Android. N’incluez jamais de mot de passe, de code de vérification ni de données de paiement sensibles.

Pour une proposition de partenariat, présentez brièvement votre organisation, l’objet de la collaboration et vos coordonnées professionnelles.
